{# Valori nutrizionali, in forma di etichetta: kcal in evidenza e tre pastiglie con la parola intera e un puntino colorato (proteine blu, carboidrati arancio, grassi rosso). Lo stile e' in base.html (.nutri-*), cosi' e' uno solo per menu, carrello, cesto, pasto aziendale e piano della settimana. Un valore mancante (kcal NULL) si dice, non si finge zero. `compatto` riduce il corpo e toglie il bollino del regime, per le tabelle. #} {% macro pastiglie_macro(prot, carb, grassi, compatto=False) -%} Proteine {{ (prot or 0)|round|int }} g Carboidrati {{ (carb or 0)|round|int }} g Grassi {{ (grassi or 0)|round|int }} g {%- endmacro %} {% macro etichetta_kcal(kcal, compatto=False) -%} {{ kcal }} kcal {%- endmacro %} {% macro nutrizione(o, compatto=False, mostra_regime=True) -%} {%- if o.kcal is not none -%} {{ etichetta_kcal(o.kcal, compatto) }} {%- if o.proteine_g is not none or o.carboidrati_g is not none or o.grassi_g is not none %} {{ pastiglie_macro(o.proteine_g, o.carboidrati_g, o.grassi_g, compatto) }} {%- endif %} {%- if mostra_regime %} {%- if o.is_vegan %}🌱 vegano {%- elif o.is_vegetarian %}🥬 vegetariano{% endif %} {%- endif %} {%- elif not compatto -%} valori nutrizionali non indicati {%- endif -%} {%- endmacro %} {# Totali gia' calcolati (carrello, piano): stesse pastiglie, senza oggetto. #} {% macro nutrizione_totali(kcal, prot, carb, grassi, compatto=False) -%} {{ etichetta_kcal(kcal, compatto) }} {{ pastiglie_macro(prot, carb, grassi, compatto) }} {%- endmacro %}
