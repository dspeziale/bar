    Gmail

    Come configurare
    1. Abilita 2-Step Verification sul tuo account Google
    2. Vai su Account Google → Sicurezza → App password
    3. Crea una password per "App personalizzata" → QuickLunch
    4. Incolla qui sotto quella password (16 caratteri)
    {# Google OAuth #}

    OAuth Google (Login con Google)

    Come ottenere le credenziali
    1. Vai su Google Cloud Console
    2. Crea un progetto → API e servizi → Credenziali
    3. Crea ID client OAuth 2.0 (tipo: Applicazione web)
    4. Aggiungi URI di reindirizzamento autorizzato:
      {{ request.host_url.rstrip('/') }}/auth/google/callback
      {{ request.host_url.rstrip('/') }}/t/google/callback
    5. Copia qui ID client e Client secret
