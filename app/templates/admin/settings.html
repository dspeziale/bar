    OAuth Google (Login con Google)

    Come ottenere le credenziali
    1. Vai su Google Cloud Console
    2. Crea un progetto → API e servizi → Credenziali
    3. Crea ID client OAuth 2.0 (tipo: Applicazione web)
    4. Aggiungi URI di reindirizzamento autorizzato:
      {{ request.host_url.rstrip('/') }}/auth/google/callback
      {{ request.host_url.rstrip('/') }}/t/google/callback
    5. Copia qui ID client e Client secret

    Backup

    Scarica una copia integrale del database in un unico file JSON: tutte le tabelle, riga per riga. Funziona sia sul database locale sia su quello di produzione.

    Il file contiene dati personali dei clienti e credenziali di servizio (token Telegram, password applicativa Gmail, chiavi delle notifiche). Conservalo come conserveresti un archivio contabile.
    Scarica il backup

    Ripristino

    Carica un file di backup: il contenuto attuale del database viene sostituito da quello del file. Al termine si viene disconnessi, perché anche gli utenti sono stati sostituiti.

    {{ csrf_field() }}
    {# ── Reset totale ── #}

    Azzeramento completo

    Operazione irreversibile. Svuota tutte le tabelle — clienti, ordini, movimenti, catalogo, convenzioni, etichette, impostazioni — e ricrea i soli dati di base: permessi, ruoli, super admin, categorie, slot, articoli del banco e impostazioni predefinite.
    Le credenziali del super admin tornano a quelle predefinite, e verrai disconnesso.
    Scarica un backup prima di procedere.

    Diverso dal reset della pagina Manutenzione, che è parziale: quello lascia in piedi tavoli, convenzioni, prenotazioni e impostazioni.
